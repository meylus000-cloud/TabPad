# TabPad — планшет Toshiba AT200 як мишка й клавіатура для ноутбука

Дві маленькі програми:

- **TabPad.exe** — для ноутбука (Windows 10). Один файл, без встановлення, нічого не потрібно ставити. У фоні лише чекає на команди, тому майже не навантажує систему. Живе в треї.
- **TabPad.apk** — для планшета (Android 4.0.3+). Тачпад, кнопки миші, клавіатура (з українською), Ctrl/Alt/Shift/Win, стрілки, Alt+Tab, копіювати/вставити, гучність тощо.

## Як отримати програми (збірка на GitHub)

1. На github.com створіть новий репозиторій (наприклад `tabpad`).
2. Завантажте в нього **весь вміст цієї папки**, включно з прихованою папкою `.github` (Add file → Upload files, перетягніть усе). Гілка має називатися `main`.
3. Відкрийте вкладку **Actions** — запуститься збірка «Build TabPad» (≈3–5 хв). Якщо не запустилась — Actions → Build TabPad → Run workflow.
4. Коли збірка зелена, на головній сторінці репозиторію справа в **Releases → «TabPad (остання збірка)»** лежать обидва файли: `TabPad.apk` та `TabPad.exe`. (Також їх можна взяти з Artifacts у самій збірці.)

## Запуск

**Ноутбук:** запустіть `TabPad.exe`. Windows спитає про брандмауер — дозвольте доступ (і для приватних, і для публічних мереж, бо мережа через USB часто вважається публічною). У вікні буде IP-адреса ноутбука та 6-значний **PIN**.

**Планшет:** встановіть `TabPad.apk` (дозвольте «Невідомі джерела»), відкрийте, натисніть «Знайти ноутбук» (або введіть IP вручну), введіть PIN, «З'єднатися». IP та PIN запам'ятовуються — наступного разу підключення автоматичне.

## Підключення кабелем (найменша затримка)

1. З'єднайте планшет і ноутбук USB-кабелем.
2. На планшеті ввімкніть **USB-модем / USB tethering** (приблизно: Налаштування → Бездротові мережі → Ще → Модем/Точка доступу → USB-модем). Windows 10 сама підхопить мережу (драйвер RNDIS вбудований).
3. Запустіть TabPad на обох пристроях → «Знайти ноутбук».

Якщо на AT200 USB-модему немає або Windows його не бачить — працює і Wi-Fi (одна мережа, або точка доступу ноутбука/роутера); для локальної мережі затримка теж мала.

## Керування

- 1 палець — курсор; тап — ліва кнопка; тап двома пальцями — права; двома пальцями вести — прокрутка; тап і одразу утримати та вести — перетягування.
- Кнопки «Ліва / Середня / Права» під тачпадом тримаються, поки натиснуті.
- «⌨ Клавіатура» — екранна клавіатура планшета; символи (в т.ч. українські) друкуються на ноутбуці. Мову на ноутбуці міняє кнопка «Мова» (Win+Space).
- Ctrl / Alt / Shift / Win — «липкі»: натисніть, потім натисніть іншу клавішу/літеру, і модифікатор сам відпуститься.
- Кнопка «Назад» на планшеті відкриває/закриває екран підключення; «⚙ Підключення» — те саме.

## Безпека

PIN зберігається в `%APPDATA%\TabPad\pin.txt` (можна змінити, відкривши файл і перезапустивши програму). Без правильного PIN керувати ноутбуком неможливо. Не відкривайте порт 5555 в інтернет — програма розрахована на кабель/домашню мережу.

## Відомі обмеження

- Ctrl+Alt+Del програмно надіслати неможливо (обмеження Windows).
- Програма не керує екраном входу Windows і вікнами від імені адміністратора (UAC) — для них запустіть TabPad.exe від адміністратора.
- Через інтернет (поза локальною мережею) програма не розрахована — це збільшило б затримку й ризики.
